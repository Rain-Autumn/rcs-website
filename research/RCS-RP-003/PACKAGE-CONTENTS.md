# RCS-RP-003 · paquet d’étude v2.0

Ce paquet réunit le rapport complet de neuf pages, son manuscrit éditable, les 220 mesures brutes, les synthèses par cas, le classeur, les contrôles d’intégrité, les références et les scripts de reproduction.

Les fichiers des corpus publics ne sont pas redistribués. Le manifeste indique leurs sources, versions et empreintes; le script les récupère depuis les sources publiques épinglées, puis vérifie longueurs et empreintes avant les essais. Canterbury, Canterbury Large et Silesia totalisent 225 908 846 octets de données d’entrée.

Les résultats portent sur un seul système Windows/NTFS et ne prédisent pas le gain d’un PC personnel. Les mesures comparent ZIP à la taille logique et NTFS aux octets alloués avant compression. Aucune donnée personnelle n’a été analysée ni supprimée.

Le DOI `10.5281/zenodo.23233639` est réservé, mais le dépôt Zenodo n’est pas publié.

Consulter `README.md` et `study-manuscript.md` pour le périmètre, les limites, les références et les commandes de reproduction. Le paquet n’inclut pas les fichiers de corpus ni aucun contenu utilisateur.
